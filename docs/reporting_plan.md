# Community reporting plan

## Current prototype

- Distinguishes emergency rescue needs from non-emergency observations.
- Presents Lagos emergency short numbers 112 and 767 as telephone calls, not USSD.
- Prepares a structured text report locally for user review.
- Links to Lagos State Citizens Gate, its official WhatsApp channel, and its non-emergency phone line.
- Does not store, transmit, or claim government receipt of a report.

## Before direct submission or storage

Obtain written agreement and an API or documented intake workflow from the responsible Lagos State agency. Define consent, retention, deletion, precise-location handling, photo redaction, abuse prevention, duplicate reports, moderation, status updates, and an escalation policy. Never treat an unverified community report as confirmed flood evidence or automatically change the public risk score from one report.
